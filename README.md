# SRT字幕翻译器 README

## 项目简介
SRT字幕翻译器是一款基于DeepSeek API开发的图形化工具，专为英文字幕文件（.srt）的中文翻译设计。工具具备**上下文感知翻译**能力，能参考前后字幕内容和历史翻译结果，确保术语一致性和语句连贯性；同时支持断点续译、多编码格式兼容等实用功能，适用于影视字幕、课程字幕等各类SRT文件的翻译需求。


## 主要功能
| 功能模块                | 详细说明                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| 上下文感知翻译          | 翻译时自动参考当前字幕的前后5条内容（可配置）及历史翻译结果，确保术语、风格一致性；支持“两遍翻译流程”（初步翻译→提炼优化），提升译文流畅度。 |
| 断点续译                | 翻译中断（如网络问题、主动中止）后，重新启动可从上次中断位置继续翻译，无需从头开始。 |
| API密钥验证             | 支持提前验证DeepSeek API密钥有效性，避免翻译过程中因密钥问题失败。         |
| 多编码格式支持          | 自动检测并适配SRT文件的多种编码（UTF-8、GBK、Latin-1等），解决乱码问题。  |
| 实时日志与API交互显示   | 日志区域实时展示翻译进度、API请求状态、错误信息，方便调试和问题排查。     |
| 多种输出格式            | 支持3种字幕输出格式：仅显示中文、中文在上+英文在下、英文在上+中文在下。   |
| 特殊字符自动处理        | 自动将英文双引号（"）替换为单引号（'）、反斜杠（\）替换为双反斜杠（\\），符合字幕规范。 |


## 环境要求
- **Python版本**：3.8 及以上（推荐3.10+）
- **依赖包**：
  - `requests`（用于API请求）
  - `tkinter`（图形界面，Python标准库自带，无需额外安装）


## 安装步骤
### 1. 准备项目文件
- 下载项目所有文件（包括 `srt_translator_context.py` 及相关配置文件），将文件放在同一目录下。

### 2. 安装依赖
打开终端/命令提示符，执行以下命令安装所需依赖：
```bash
pip install requests
```

### 3. 获取DeepSeek API密钥
1. 访问 [DeepSeek官方平台](https://www.deepseek.com/) 并注册/登录账号。
2. 进入“API密钥管理”页面，创建并复制你的API密钥（注意：密钥需妥善保管，避免泄露）。


## 使用指南
### 1. 启动程序
在项目目录下，通过终端执行以下命令启动图形界面：
```bash
python srt_translator_context.py
```
或直接双击 `srt_translator_context.py` 文件（需确保Python已添加到系统环境变量）。

### 2. 配置API密钥
1. 在程序顶部的“API密钥”输入框中，粘贴你的DeepSeek API密钥。
2. 点击“验证密钥”按钮，确认密钥有效性（日志区域会显示验证结果）。

### 3. 添加SRT文件
1. 点击“添加文件”按钮，在弹出的文件选择窗口中，选择1个或多个 `.srt` 格式的字幕文件。
2. 如需移除文件：选中文件列表中的文件，点击“移除选中”；点击“清空”可删除所有添加的文件。

### 4. 设置输出格式
在“字幕格式”区域，选择所需的输出样式：
- **只显示中文**：输出文件仅包含中文翻译。
- **中文在上**：输出文件中，中文翻译在上，英文原文在下。
- **英文在上**：输出文件中，英文原文在上，中文翻译在下。

### 5. 开始翻译
1. 确认API密钥验证通过、文件已添加后，点击“开始翻译”按钮。
2. 翻译过程中，进度条会显示总体进度和当前文件进度；日志区域会实时显示API请求状态、翻译进度等信息。
3. 如需中断翻译：点击“中止”按钮，程序会保存当前进度，后续可通过“续译”恢复。

### 6. 续译功能
1. 若翻译中断（如关闭程序、网络断开），重新启动程序后，系统会自动检测未完成的进度。
2. 确认已添加相同的SRT文件后，“续译”按钮会变为可用状态，点击即可从上次中断位置继续翻译。

### 7. 查看输出文件
翻译完成后，输出文件会保存在原SRT文件的同一目录下，文件名格式为 **“原文件名_translated.srt”**（例如：`movie.srt` → `movie_translated.srt`）。


## 配置说明
### 1. 提示词配置
程序内置了优化后的翻译提示词（包含“两遍翻译流程”“上下文一致性”“特殊字符处理”等规则），如需自定义：
1. 在“翻译提示词”输入框中修改内容。
2. 提示词会直接影响翻译质量，建议参考内置提示词的结构，保留关键规则（如特殊字符处理、上下文要求）。

### 2. 上下文窗口配置
默认情况下，上下文管理器会参考当前字幕前后各5条内容（`context_window=5`），如需调整：
1. 打开 `srt_translator_context.py` 文件。
2. 找到 `ContextManager` 类的初始化代码（`def __init__(self, context_window: int = 5):`）。
3. 修改 `context_window` 的默认值（如改为3或7），保存后重启程序。


## 常见问题（FAQ）
### Q1：API密钥无效或验证失败怎么办？
- 检查密钥是否正确（注意前后无空格）。
- 确认密钥未过期（DeepSeek API密钥有有效期，需在官方平台重新获取）。
- 检查网络连接，确保程序能访问DeepSeek API（https://api.deepseek.com）。

### Q2：打开SRT文件时出现“编码错误”怎么办？
- 程序会自动尝试多种编码格式，若仍失败，可手动转换文件编码（如用Notepad++将文件转为UTF-8格式）。

### Q3：翻译中断后，“续译”按钮不可用？
- 确认已添加与上次翻译相同的SRT文件（路径、文件名需一致）。
- 检查是否存在 `.translation_progress.json` 文件（进度记录文件，删除后会丢失续译数据）。

### Q4：翻译速度慢怎么办？
- 程序默认在每条字幕翻译后延迟0.8秒（避免API请求过于频繁），如需调整，可修改 `translate_subtitles` 方法中的 `time.sleep(0.8)` 语句（不建议设为0，可能触发API限流）。
